# 到货分拣台 · 珠宝镶嵌宝石分拣

供应商裸石包到货后的分拣台：先核身份，再按订单质量派石，异常石不占订单镶位。

## 分拣规则

- **身份核对（待核对 → 不能派石、不占镶位）**
  - 证书号与其他石重号
  - 腰码（腰棱激光镭射码）缺失
  - 编号在不同包裹间重复
- **核对通过**：身份无异常且满足订单质量 → 已放行，占用订单镶位
- **换货**：尺寸超出订单公差，或颜色等级低于订单要求 → 标记换货，
  原记录保留，换货石不占订单数量；换货收回后可重新进入待镶嵌
- **订单清单**每单显示：已放行 / 待换货 / 未分配（需求数 − 已放行）
- 预置三包（PK2609A / PK2609B / PK2609C）14 颗，覆盖证书重号、
  腰码缺失、编号跨包重复、尺寸超差、色级不足、已放行、换货等场景

## 文件分层维护

| 关注点 | 文件 |
| --- | --- |
| 规则（色级顺序、公差、身份/质量判定、订单计数） | `src/rules.ts` |
| 存档（三包预置裸石与订单出厂数据） | `src/archive.ts` |
| 浏览器存储（localStorage 读写与恢复预置） | `src/storage.ts` |
| 页面（分拣台、筛选、订单清单） | `src/App.tsx` + `src/components/` |
| 数据契约（类型定义） | `src/types.ts` |

所有数据只保存在浏览器 localStorage，不发送网络请求；
页面内「恢复预置三包」可随时回到出厂数据。
